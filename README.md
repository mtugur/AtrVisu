# AtrVisu Standards Pack v0.3

Bu paket AtrVisu için kalıcı platform standartlarını repo içine taşımak amacıyla hazırlanmıştır. Paket bir feature implementasyonu değildir; ürün mimarisi, UX standardı, veri modeli, komut/panel protokolü, simülasyon mimarisi ve geliştirme yönetişimi için başvuru kaynağıdır.

## Kullanım İlkesi
- Chat veya geçici promptlar kaynak kabul edilmez; repo içindeki standart dosyaları kaynak kabul edilir.
- Mevcut çalışan dokümanlar silinmez; bu paket yeni standart klasörleri ekler.
- Kod değişikliği yapılmadan önce ilgili standart dosyası okunur.
- UI, veri modeli, komut sistemi, panel sistemi, simülasyon ve koordinat kararları rastgele alınmaz; ilgili standart veya ADR ile bağlanır.

## Klasörler
- `AGENTS.md`: Codex/agent çalışma kuralları.
- `docs/standards/`: Kilitlenmiş platform, UX, veri modeli, simülasyon ve kalite standartları.
- `docs/roadmap/`: Katmanlı ürün yol haritası.
- `docs/protocols/`: Codex senkronizasyon ve görev protokolleri.
- `docs/checklists/`: Feature erişim ve kalite kapıları.
- `docs/templates/`: Görev ve ADR şablonları.
- `docs/contracts/`: Platform contract taslakları.

## Versiyon
v0.3 — AtrVisu Master Plan v3.0 ile hizalıdır.
