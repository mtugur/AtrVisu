# AtrVisu Layered Master Plan v3.0

## Phase 0 — Platform Contracts and Stabilization
Amaç: Üzerine ürün inşa edilecek güvenilir zemin.

Zorunlu çıktılar:
- Command contract
- Panel contract
- Entity contract
- Selection contract
- Viewport contract
- legacy adapters
- contract tests
- feature access matrix
- no-red-console e2e gate

Kapanış:
- Panel collapse scene/camera/entity davranışını bozmaz.
- Hiçbir UI refactor mevcut özellikleri gizlemez.
- Console temizdir.

## Phase 1 — Speed / Quotation Tool
Amaç: Liveline benzeri hızlı satış/layout aracı.

Capabilities:
- Asset Browser
- Layout Explorer
- drag/drop placement
- smart connectors foundation
- fast editing
- viewpoints / presentation mode
- BOM/export/report foundation
- customer-ready 2D/3D output

Kapanış:
- 15 dakikada müşteri toplantısında kullanılabilir layout ve çıktı.

## Phase 2 — Layout Engineering and Verification
Amaç: FDU/Visual Components yönünde mühendislik doğrulama.

Capabilities:
- group-as-assembly behavior
- selection cycling / pick list
- Z alignment and 3D arrange tools
- clearance/collision reports
- measurement/markup
- 2D plan/floor reference
- DWG/background reference foundation

## Phase 3 — Engineering Simulation
Amaç: Emulate3D mantığında throughput ve darboğaz analizi.

Capabilities:
- deterministic scenario runner
- flow primitives
- cycle time / processing time / queue capacity
- bottleneck reports
- metrics dashboard
- replay and comparison

## Phase 4 — Smart Components and Virtual Commissioning Bridge
Amaç: Visual Components benzeri smart eCatalog ve PLC bridge.

Capabilities:
- smart component definition
- signal ports
- state machine behavior
- OPC UA/MQTT bridge service
- signal mapping UI
- scenario/control validation

## Phase 5 — Enterprise Digital Twin Direction
Amaç: Tecnomatix yönünde uzun vadeli kurumsal özellikler.

Capabilities:
- robot kinematic chain
- path replay / OLP adapters
- multi-robot collision planning
- collaboration and review sessions
- digital thread / external system integration
- marketplace / AI assistant
